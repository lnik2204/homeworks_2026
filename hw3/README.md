# Задание 2: Guessing game на сокетах

## Описание задачи
Нужно реализовать игру в угадывание числа. Игра инициируется клиентом при отправке протокольного сообщения “HELO” на сервер. В ответ на “HELO” сервер проверяет, есть ли IP клиента в таблице активных игр. Если IP клиента в таблице отсутствует, сервер инициализирует игру с клиентом, посчитав CRC32(IP) и инициализировав это как seed для генерации случайного числа в промежутке от 1 до некоторого случайного числа ( сидом вы устанавливаем генерацию и верхней границы промежутка из диапазона от 100 до 1000, и числа из него). Затем сервер высылает в ответ клиенту протокольное сообщение “WLCM lower_bound upper_bound”, где lower_bound – нижняя граница промежутка, upper_bound – верхняя. Клиент, получив WLCM-сообщение, и сервер, отправив его, входят в состояние игры друг с другом: клиент отправляет протокольные сообщения “GUES” с синтаксисом “GUES number”, где number – число, которое вводится пользователем с input’а. В ответ на GUES-сообщение сервер возвращает одно из сообщений: “MORE”, “LESS” или “BING”. В случае с MORE- и LESS-сообщениями сервер не отправляет дополнительной информации (это сообщение служебное и служит для передачи
информации о том, больше или меньше загаданное число относительно предположения клиента), в случае с BING число угадано, и сервер возвращает победный ключ (64-значная hex-строка, хэш от IP-адреса и загаданного числа вместе). Если число не было угадано клиентом за log2(range) попыток, сервер отсылает сообщение “FAIL” и удаляет из таблицы записей IP клиента. 

GGTP — протокол для игры в угадывание числа поверх UDP.

### Формат сообщений

| Сообщение | Синтаксис | Описание |
|-----------|-----------|----------|
| HELO | `HELO [timeout]` | Инициализация игры (тайм-аут опционален) |
| WLCM | `WLCM a b` | Приветствие с границами диапазона |
| GUES | `GUES N` | Попытка угадать число |
| MORE | `MORE` | Загаданное число больше |
| LESS | `LESS` | Загаданное число меньше |
| BING | `BING <key>` | Победа, возвращается ключ (64 hex) |
| FAIL | `FAIL` | Поражение (попытки исчерпаны) |
